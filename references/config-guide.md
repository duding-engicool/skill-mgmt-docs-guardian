# 配置说明（`.cb-index/config.json`）

首次扫描会自动生成一份配置。**其中 `doc_no_patterns` 最关键**——它决定文件编号能否被识别，进而决定引用关系能否建立、影响分析准不准。

## 一、自动推断机制（首次扫描时）

扫描器会用 5 条候选正则去匹配「文件名 + 文档标题 + 首段正文」，命中数 ≥ 3 且最多的前 3 条会被写入配置：

| 候选 | 示例命中 |
|---|---|
| `[A-Z]{2,4}[-_/]\d{2}[-_/]\d{2,3}` | `QP-7.5-01`、`WI-03-012` |
| `[A-Z]{2,4}[-_/]\d{3,4}` | `QP-0123`、`WI-001` |
| `[A-Z]{1,3}/[A-Z]{1,3}[-_/]\d{2,3}` | `QM/QP-01` |
| `[A-Z]{2,}-\d{3,}` | `ABC-001` |
| `[A-Z]{2,4}\d{4,6}` | `QP0001` |

推断结果会打印在运行日志里。**如果识别错了，直接改配置后重新扫描即可**，旧快照不会因此损坏。

## 二、字段说明

| 字段 | 作用 | 建议 |
|---|---|---|
| `doc_no_patterns` | 文件编号正则数组 | 多个规则会依次尝试；写你体系真实的编号格式 |
| `clause_pattern` | 条款号正则，用于定位"第几条" | 默认 `\d{1,2}(\.\d{1,2}){0,3}`，一般不用改 |
| `version_keys` | 识别版本号的关键词 | 若你的文件用"版次/A-2"之类，补充关键词 |
| `effective_date_keys` | 识别生效日期的关键词 | 同上 |
| `owner_keys` | 识别责任人的关键词 | 建议加上你们实际的岗位字段名 |
| `ignore_globs` | 被忽略的文件名通配 | 默认已含 Word 临时文件 `~$*` |
| `ignore_dirs` | 被忽略的目录名 | **务必把"作废/旧版本/备份"目录加进来** |
| `max_files_warning` | 预检时的文件数告警阈值 | 默认 2000 |
| `history_keep` | 保留最近多少份快照 | 默认 24；快照只存映射，占用极小 |
| `booktitle_refs` | 是否抽取《书名号》引用 | 强烈建议保持 true，中文体系文件主要靠它 |
| `filename_refs` | 是否用文件名匹配引用 | 默认 true |

## 三、编号识别失败的后果

若编号规则没配上，`doc_key` 会退化成文件路径。后果：

- 文件被移动或重命名 → 被误判为"删除一个 + 新增一个"
- 编号引用抽不到 → 图谱大量散点，影响分析基本失效
- 仅剩《书名号》引用可用（仍有一定效果）

**判据**：跑完看 `体系台账.csv` 里"编号"列是否大面积为空。若为空，说明编号规则没生效，需要手工填 `doc_no_patterns`。

## 四、忽略规则为什么重要

几百份文件的目录里几乎必然混有：

- Word 临时锁文件 `~$xxx.docx`（默认已排除）
- "旧版本""作废""备份"子目录（**默认只排除了常见中文名，请按实际情况补充**）
- 个人副本、导出件、邮件附件

不加忽略规则，这些会污染台账、制造大量假变更，并让"孤立文件"列表失去意义。

## 五、索引目录说明

```
<目标文件夹>/.cb-index/
├── config.json        配置（可手工编辑）
├── STATUS.md          给 Agent 读的交接笔记
├── decisions.json     人工标注为"已忽略"的影响项
├── objects/           内容寻址对象库（相同内容只存一份）
├── snapshots/         快照清单 + latest 指针
└── reports/           报告、待办清单、关系图、台账
```

- 删除整个 `.cb-index/` 不影响原始文件，仅失去历史对比能力
- 想彻底重来：`python scan.py --path "..." --reset`
